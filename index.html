Aluno: Vitor Humel Silva

Curso: Engenharia da Computação

Objetivo do sistema: Criar um portal acadêmico para reunir informações importantes para estudantes, professores e visitantes.

Sobre o IFSP Connect

O IFSP Connect é um projeto desenvolvido ao longo da disciplina de Desenvolvimento Front-End.

Durante as próximas missões, novos conteúdos e recursos serão adicionados ao projeto.

Ao final da jornada, o IFSP Connect será uma aplicação web completa, organizada e interativa.

PROPÓSITO DO PROJETO

A finalidade da nossa plataforma é construir a estrutura lógica essencial para o desenvolvimento front-end. Utilizando o HTML como pilar principal, buscaremos evoluir progressivamente o domínio técnico necessário para planejar e executar projetos dessa natureza, cujos avanços serão demonstrados continuamente no próprio portal IFSP-CONNECT.

VISÃO GERAL E RECURSOS

O portal IFSP-CONNECT visa proporcionar uma imersão digital completa na rotina do IFSP Campus Guarulhos. O site reunirá informações sobre iniciativas em andamento e programações futuras, contando com os seguintes elementos estruturais:

  • Página Inicial (Home)
  • Informações Institucionais
  • Acervo Visual (Imagens)
  • Canal de Contato (Formulário)
  • Mural de Notícias
  • Guia de Cursos
  • Design Responsivo
  • Cronograma de Eventos
  • Módulos Interativos
  • Validação de Dados em Formulários

Nossa proposta central é desenvolver uma plataforma web intuitiva que sirva como um manual prático para a comunidade acadêmica e visitantes. O portal reunirá recursos fundamentais tanto para novos estudantes quanto para veteranos, garantindo acessibilidade a todos. Na tela principal, o público encontrará novidades atualizadas sobre projetos de extensão, qualificações gratuitas, ações estudantis e auxílios financeiros, com exibições personalizadas com base nos interesses de cada usuário. No painel institucional, estará disponível a listagem completa dos cursos ofertados pelo instituto, incluindo modalidades de licenciatura, bacharelado e pós-graduação.

O site também contará com um espaço dedicado a registros fotográficos compartilhados por alunos e docentes, destacando aulas práticas, projetos concluídos e celebrações do campus. Além disso, o calendário de eventos organizará as principais atividades semestrais e anuais. Os estudantes matriculados poderão salvar datas relevantes em suas agendas pessoais para receber alertas diretamente no sistema sempre que acessarem o site.

Para concluir, a seção de contato permitirá que os usuários enviem sugestões e apontem melhorias no sistema. Essa troca direta de feedback entre o público e os desenvolvedores garantirá atualizações contínuas, tornando a plataforma cada vez mais funcional, moderna e alinhada às necessidades de todos.

SOBRE O CURSO DESENVOLVIMENTO FRONT-END

O curso de desenvolvimento front-end prepara o estudante para construir a interface digital com a qual o usuário interage diretamente. No centro desse aprendizado está o HTML (HyperText Markup Language), que funciona como o esqueleto ou a fundação de qualquer site na internet. Sem essa linguagem, seria impossível organizar os elementos de uma página, pois é ela que define onde ficam os textos, os títulos, as imagens, os formulários e os botões através de um sistema de tags estruturadas.

Dessa forma, aprender HTML no início da jornada de front-end estabelece a base necessária para o sucesso com as tecnologias seguintes. Uma estrutura HTML limpa e bem organizada facilita a aplicação de estilos visuais complexos com o CSS e torna a manipulação de elementos muito mais eficiente quando o desenvolvedor começa a adicionar interatividade dinâmica com o JavaScript ou frameworks modernos.
