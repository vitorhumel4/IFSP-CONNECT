# IFSP Connect

Portal acadêmico fictício desenvolvido ao longo da disciplina de **Desenvolvimento Front-End**. A cada missão, novas funcionalidades são adicionadas, e ao final o projeto será uma aplicação web completa, com páginas estruturadas em HTML, estilos em CSS e interatividade em JavaScript.

> **Status:** em desenvolvimento 🚧

## Sobre o projeto

O IFSP Connect reúne informações importantes para estudantes, professores e visitantes do **IFSP Campus Guarulhos**: cursos, eventos, notícias, galeria de imagens e um canal de contato para sugestões e feedback.

O projeto também serve como portfólio, mostrando a evolução do domínio técnico em front-end ao longo da disciplina.
